## Descripcion
Implementacion de un Pac-Man basico en Java aplicando conceptos de Programacion Orientada a Objetos.

## Estructura del proyecto
```
PacmanBasico/
├── src/
│   ├── pacman/
│   │   ├── modelo/          # Clases del dominio del juego
│   │   └── controlador/     # Controlador con patron Singleton
│   └── test/                # Tests con main() y prints
└── README.md
```
